# Student Marks Calculator

A beginner-friendly student project built with HTML, CSS, and JavaScript.

## Features
- Enter a student name and marks for five subjects
- Calculate total marks out of 500
- Calculate the overall percentage
- Display a grade from A+ to F
- Show pass/fail status (minimum 35 marks in every subject)
- Validate marks and show helpful error messages
- Clear the form and use the responsive layout on mobile or desktop

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter marks from 0 to 100 for all five subjects.
4. Select **Calculate result**.

## Files
- `index.html` — page structure and form
- `style.css` — design and responsive layout
- `script.js` — calculations, grading, and validation

## Note
The pass mark and grade boundaries are examples for this project. Change them in `script.js` if your institution uses different rules.
